# jinyong-fiction-craft

金庸作品细读支持的小说创作参考库。帮助作者在构思、写作和修改时，找到原文中的具体安排，比较相近选择及其适用条件，再决定怎样用于自己的作品。

当前为 **v0.3.0 本地审阅版**：保留《连城诀》《射雕英雄传》《笑傲江湖》的十二页细读，加入《神雕侠侣》《天龙八部》《鹿鼎记》的五页比较材料。可通过文件路径调用；不据阅读覆盖或少量样稿宣称成稿效果稳定改善。

## 定位

关注细节、感知、语言、人物互动与叙事连接：原文怎样安排；另一种安排可能改变什么；当前作品需要什么条件才值得参考。支持查例、比较、构思和局部修改，尊重使用者已有的人物、题材、视角与表达目的。

具体写法可以是模型已经知道的办法。参考库的价值还在于展示展开过程、条件和取舍，不以是否作者独有或模型从未想到作为唯一标准。

## 如何形成材料

- 文本观察对应具体段落及前后文；跨章判断核对实际连接过程。
- 编辑推断和替换、删改比较明确标注，不能当作作者意图或已验证的读者反应。
- 应用建议说明当前稿件需要的条件，也可以判断不适用；不移植原作人物与事件。
- 通用提醒用于导航，具体细读保留在一个位置，问题入口直接链接过去。

## 如何判断价值

分别判断材料是否忠于原文、使用者能否找到并选用、成稿是否有值得保留的变化。读过、机制对应和收益得到证明是不同的判断；题面已有安排与普通编辑选择不自动记为库的贡献。一次结果不佳，先查来源、选读、模型执行与归因，再决定是否修改库。

此前 v0.2.0 阶段，扩书前库与四道题预先冻结，三条件小对照实际保留11份首次答卷；一份跳过必读入口，按约定停止，最后一份未运行。另有一道题与整理时的例子过近，不作独立新题证据。剩余对照未显示稳定的额外成稿收益，也没有覆盖大部分新增细读；原样答卷、用量、具体得失与偏差另存 `.local/two-books-20261105/evaluation/comparison.md`。这是合成练习，不是独立文学基准，不能拆分断言某一本书的独立收益。

v0.3.0 扩充后，另完成六题、三条件共18份首次答卷，由主代理本人评阅。已有LCJ-D等组织安排确实被选读并落实；新增五页中，只有LDJ-C在一次定向阅读中完整读过，随后未被采用，其余四页尚无采用后的成稿证据。部分成稿有可保留的变化，但没有证明新增三书使写作稳定变好。本次SDXL-T偷袭条件、LDJ-L口头应允的修正发生在这些比较之后，未重测。具体得失、未完成项及本地证据位置统一见[本批审阅说明](docs/three-books-batch.md)。

## 本地材料与仓库范围

仓库维护原创分析、必要短引及来源定位。全集原书放在忽略的 `data/` 中，选书包、图片、逐段全文和转换产物放在忽略的 `.local/` 中，不进入版本控制。原文定位使用 EPUB 文件与段号，不冒充纸书页码。

使用 `book-to-skill` 处理提取和阅读覆盖，按小说材料调整分析模板；用 `skill-creator` 的按需读取原则整理入口。公开项目仅供对照，不代替原文依据。
