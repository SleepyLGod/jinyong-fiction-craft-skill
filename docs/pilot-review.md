# 《连城诀》首部试点记录

日期：2026-10-30。版本：0.1.0。本地项目，不提交或推送。

## 本轮完成了什么

定位为“用书源帮助作者比较与选择的创作参考库”。入口采用作者当前会问的问题，直接链接六组具体安排；详细分析只有一份，不按十二回再复制十二份摘要。

《连城诀》十二回、新序、后记已逐块读完，共49个完整显示的文本分块。图辑题注也已读；26张图片内容不在本轮分析内。提取包和各 XHTML 指纹已核对；书名、章节号、段号规则在来源记录中，原文和阅读记录保存在忽略的 `.local/`。

## 六组材料依据和边界

| 材料 | 原文足以支持的观察 | 没有据此认定 |
|---|---|---|
| LCJ-D | 醒转后先受动作阻碍再辨伤；铃声打断吃饭并改变是否见人的选择 | 感官词越多越生动，或所有心理都应藏起来 |
| LCJ-C | 同一解救动作被双方按各自所知解释，回应继续影响下一步；数字口授因不同所知引出不同反应 | 误会一定让人物立体，或应为每个场景制造误会 |
| LCJ-R | 分食、做衣、拒衣、继续合作与后来误读衣物，各有前后条件 | 礼物使关系必然好转，或羽衣已证明狄水恋情 |
| LCJ-P | 乌蚕衣反复挡住刺入，仍有疼痛、昏倒、未覆盖处和招法不足；背刺获救后仍面对师父的选择 | 宝物万能，或给所有物件设置缺陷就会改善情节 |
| LCJ-L | 笑声句末修正客观范围；离谷结尾逐步撤去人声、人物和飞禽，再停到流水 | 固定长短句比例、段尾禁情绪词，或两段即代表作者整体语言 |
| LCJ-N | 目击新骗局帮助理解旧案；确信杀人仍未等于确认死亡，末回才补凸砖与梦行解释 | 全链早已公开足够线索，或戚芳当时的解释都是事实 |

“换一种顺序/删去一段会改变侧重”等说法明确标为编辑分析。本轮没有把这些比较冒称作者的自述理论或已经验证的读者反应。

## 从江南库带来的实际取舍

保留模型本来可能知道的通用方向，但仅作入口；细读给到的是具体顺序、所知、条件和相近方案差别。使用说明直接要求理由对应正文中的实际选择，不以“读过”“引用存在”代替收益。

同时避免把旧试题的个别失败变成新规则。没有建立大规模生成、匿名评分或新的验收系统；没有搬进江南库的内容与测试记录，也没有修改江南库。

## 可用性到哪一步

[选用示例](../examples/choosing-a-method.md)演示了一条完整的查例→比较→选取路径，也给出不采用旧经历分支的条件。这是作者编写时的走查示例，不能当独立查库测试或成稿效果测评。

来源复核、链接和文件检查只验证材料与入口的对应关系。尚未验证：新使用者是否能选对；不同模型是否能落实；正文是否更生动、人物更鲜活、叙事是否更好。也未测试各宿主的安装与自动发现。

本地检查结果：17个来源 XHTML 与此前可读的全集副本指纹一致；32个本地文件链接有效；23处完整写出的来源定位未超出相应文件段号范围。简写的后续段号结合上下文人工核对，边界检查本身不判断分析语义是否准确。`book-to-skill` 的入口及细读安全扫描通过；另将同样的文本扫描用于全部11份非本地材料 Markdown，未发现已知模式。这也不等于完整安全审计。

`skill-creator` 的 Python 快速校验器因环境缺少 PyYAML 未能运行；未安装依赖。入口 YAML 改由系统 Ruby 安全解析，名称、说明和字段另作本地检查，通过。原书及阅读全文被 Git 忽略；仓库无提交、无远端。检查记录在 `.local/pilot-checks.json`。

当前材料不足以支持金庸全集的风格概括、作品间比较和普遍长篇设计法。下一步宜先由一份真实稿件的具体问题检验这六组是否提供了值得采用的选择，再决定补内容还是调整入口；不以继续读更多册代替这一判断。
